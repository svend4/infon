# Начало работы с TVCP

Добро пожаловать в TVCP - Terminal Video Communication Platform! Это руководство поможет вам начать работу с P2P аудио+видео звонками.

## Быстрый старт (5 минут)

### 1. Сборка TVCP

```bash
# Клонировать репозиторий
git clone https://github.com/svend4/infon
cd infon

# Собрать
make build

# Проверить установку
./bin/tvcp version
```

### 2. Тест видео

```bash
# Попробовать демо со статичным изображением
./bin/tvcp demo test_pattern.png

# Тест живого видео превью
./bin/tvcp preview bounce
```

Вы должны увидеть анимированное видео в вашем терминале!

### 3. Локальный видеозвонок

Откройте два терминала:

**Терминал 1 (Алиса):**
```bash
./bin/tvcp call localhost:5001 gradient 5000
```

**Терминал 2 (Боб):**
```bash
./bin/tvcp call localhost:5000 bounce 5001
```

Вы должны увидеть:
- Разделённый экран с видео (удалённое вверху, локальное внизу)
- Статистику в реальном времени
- Индикаторы передачи аудио

Нажмите `Ctrl+C` для завершения звонка.

## Установка и обновления

### Установка в системный PATH

После сборки можно установить `tvcp` в систему для удобного доступа:

**Linux / macOS:**
```bash
# Установить в /usr/local/bin
sudo cp ./bin/tvcp /usr/local/bin/

# Или установить в пользовательскую директорию (без sudo)
mkdir -p ~/bin
cp ./bin/tvcp ~/bin/
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

# Проверить установку
tvcp version
```

**Windows (PowerShell от имени Администратора):**
```powershell
# Скопировать в директорию Windows
Copy-Item .\bin\tvcp.exe C:\Windows\System32\

# Или добавить в PATH пользователя
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$userPath;C:\tvcp\bin", "User")

# Проверить установку
tvcp version
```

### Обновление зависимостей

Если вы клонировали репозиторий давно и пакеты устарели:

```bash
# Обновить все Go зависимости до последних версий
go get -u ./...

# Очистить и проверить зависимости
go mod tidy
go mod verify

# Пересобрать с обновлёнными зависимостями
make clean
make build

# Проверить, что всё работает
go test ./...
```

**Обновление конкретного пакета:**
```bash
# Обновить один пакет
go get -u github.com/example/package

# Обновить до конкретной версии
go get github.com/example/package@v1.2.3

# Пересобрать после обновления
make build
```

**Что делает каждая команда:**
- `go get -u ./...` — обновляет все зависимости проекта
- `go mod tidy` — удаляет неиспользуемые зависимости и добавляет недостающие
- `go mod verify` — проверяет целостность загруженных модулей
- `make clean` — удаляет старые скомпилированные файлы
- `make build` — собирает новую версию программы

### Обновление TVCP

Чтобы обновиться до последней версии TVCP:

```bash
# Перейти в директорию tvcp
cd infon

# Получить последние изменения
git pull origin main

# Обновить зависимости
go mod tidy

# Пересобрать
make clean
make build

# Переустановить в систему (если устанавливали)
sudo cp ./bin/tvcp /usr/local/bin/
```

### Удаление программы

**Удалить из системного PATH:**

Linux / macOS:
```bash
# Если установлено в /usr/local/bin
sudo rm /usr/local/bin/tvcp

# Если установлено в ~/bin
rm ~/bin/tvcp
```

Windows (PowerShell от имени Администратора):
```powershell
# Если установлено в System32
Remove-Item C:\Windows\System32\tvcp.exe
```

**Удалить директорию проекта:**
```bash
# Перейти в родительскую директорию
cd ..

# Удалить весь проект
rm -rf infon
```

## Требования к терминалу

### Минимальные требования
- Поддержка 256 цветов
- Кодировка UTF-8
- Размер минимум 80×24 (рекомендуется: 120×40)

### Рекомендуемые терминалы
- ✅ **iTerm2** (macOS) - отличная поддержка
- ✅ **Terminal.app** (macOS) - хорошая поддержка
- ✅ **GNOME Terminal** (Linux) - отличная поддержка
- ✅ **Konsole** (Linux) - отличная поддержка
- ✅ **Windows Terminal** (Windows) - хорошая поддержка
- ⚠️ **PuTTY** - ограниченная поддержка цветов
- ❌ **Классический cmd.exe** - не поддерживается

## Устранение неполадок

### "Connection timeout"

**Проблема**: Не удаётся подключиться к удалённому узлу

**Решения:**
1. Проверить, что firewall разрешает UDP порт 5000
2. Убедиться, что оба узла запущены
3. Проверить подключение Yggdrasil (`tvcp yggdrasil`)
4. Попробовать сначала локальный тест (`localhost:5001`)

### "No video received"

**Проблема**: Звонок подключается, но видео не появляется

**Решения:**
1. Проверить сетевую статистику на высокую потерю пакетов
2. Попробовать проводное подключение вместо WiFi
3. Уменьшить расстояние до WiFi роутера
4. Проверить, не блокирует ли firewall UDP

### Терминал не показывает цвета

**Проблема**: Вывод чёрно-белый или искажённый

**Решения:**
1. Убедиться, что терминал поддерживает 256 цветов
2. Проверить, что включена кодировка UTF-8
3. Попробовать другой эмулятор терминала
4. Обновить программу терминала
