# Optional dependencies for the TVCP model sidecars (ai/adapters/*.py).

# Every sidecar runs WITHOUT these (model-free fallback) so you can test the
# pipeline first. Install only what you need for the feature you want to enable.

#   pip install pillow ultralytics                       # just C3 objects

# Heavy packages (torch, mediapipe, ultralytics) pull in large wheels and may
# need a matching CUDA for GPU speed; CPU works but is slower.
