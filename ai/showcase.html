TVCP-AI

Connecting any neural network to terminal graphics via the open tvcp-ai/1 format. Everything below was compiled with Go 1.24 and run for real; previews are faithful renders of the terminal output.

The rendering core

Real aidraw.exe renders a JSON draw-DSL scene into the terminal.

aidraw scenes/sunset.json

Pixel path

babe.ImageToFrame turns any raster into 2x2 quadrant blocks.

aiimg assets/aurora.png 80 50

AI plays a game

Tic-tac-toe on the repo engine + minimax, rendered as colored frames.

aiplay

A visual language

Glyph cards as a low-bandwidth visual vocabulary.

aicards

AI as a video source

A model paints frames (sketch to scene) - slow painterly video.

tvcp ai -brain URL

Open protocol - any model

A full game over real HTTP using the tvcp-ai/1 format.

braindemo -brain URL

Live vs Claude Haiku

You beat Haiku in the terminal; Haiku plays O via your API key.

aiturn -brain URL 1 1

Haiku draws (sketch)

Haiku composes a scene with the simple sketch format.

aidraw -brain URL -sketch -prompt "..."

Haiku reacts

Haiku answers with mood-matched symbol cards.

aicards -brain URL -msg "..."

New game: Wordle

The brain guesses; the repo Wordle engine gives colored feedback.

aiwordle -word GHOST

Haiku plays Wordle

Live Haiku guesses (SLATE, CORNY, OPIUM) using the feedback.

aiwordle -brain URL -word ROBOT

New game: UNO

A full UNO game over the protocol on the repo cards engine.

aiuno -brain URL
One JSON-over-HTTP contract covers moves (tic-tac-toe, Wordle, UNO), draw (full DSL + simple sketch), react (symbol cards) and a video source. Swap brains by changing a URL: reference (no model), local Ollama, or any OpenAI / Anthropic endpoint. Spec: BRAIN_PROTOCOL.md · adapters in adapters/.
